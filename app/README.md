# Aplicativo Canoa

Aplicativo desktop Windows desenvolvido com Tauri 2, Rust e TypeScript, usando WebView2 para renderizar páginas web.

Consulte o README principal na raiz do repositório para requisitos, instalação, build e informações de privacidade. O script `scripts/gerar-instalador.ps1` gera o instalador NSIS e o executável portátil em `output/`.
